## 🚀 Sobre Mim
Sou um profissional com perfil híbrido, unindo a **Engenharia Mecânica** e a **Análise de Sistemas**. Meu foco é resolver problemas industriais complexos utilizando tecnologia de ponta, gerando inteligência desde a coleta de dados no chão de fábrica até o monitoramento gerencial.

- ⚙️ **Hardware & IoT:** Desenvolvimento de sistemas embarcados (ESP32-CAM, micro-ROS, sensores).
- 👁️ **Visão Computacional & IA:** Treinamento de modelos (YOLOv8, U-Net, TensorFlow) para inspeção automatizada e conformidade normativa (ex: NR-13).
- 📊 **Engenharia de Dados & Automação:** Construção de pipelines ETL, orquestração com Apache Airflow e n8n, e modelagem de bancos de dados (PostgreSQL).
- 💻 **Software Engineering:** Desenvolvimento de aplicações Desktop e Mobile (C#, .NET, Python, C/C++) para monitoramento preditivo e dashboards em tempo real.
